Connection string for mongoose": "^8.9.1"
Mongo_URI=mongodb+srv://<username>:<db_password>@<Clustername>.<xxxx>.mongodb.net

Replace <db_password> with the password for the  database user. 
Replace <username> with the username for the  database user. 
Replace <Clustername> with the name for the  MongoDB Cluster. 
Replace <xxxx> with the subdomain for the  MongoDB server.
